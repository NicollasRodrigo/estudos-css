## 🚀 Projeto em destaque

### 🎨 Meu Portfólio — HTML e CSS

Página de portfólio desenvolvida para praticar **HTML5 e CSS3**, trabalhando navegação, seções, cards, formulário, validações e recursos multimídia.

- [Abrir projeto](./projetos/portfolio-web/)
- [README do projeto](./projetos/portfolio-web/README.md)

## 🧠 Conteúdos praticados

- Seletores por elemento, `id` e `class`
- Box Model
- Cores, tipografia e espaçamento
- Margens, preenchimento e bordas
- Menu e navegação
- Classes e reutilização de estilos
- Estados com `:hover`
- Estilização de formulários
- Organização do CSS em arquivos separados
- Integração entre HTML5 e CSS3
