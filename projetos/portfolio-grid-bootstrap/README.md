# Portfólio Grid com Bootstrap

Portfólio responsivo desenvolvido para praticar HTML, CSS, JavaScript e Bootstrap 5.

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome

## Recursos

- Layout responsivo com o sistema de Grid do Bootstrap.
- Menu de navegação adaptado para telas menores.
- Alternância entre tema claro e escuro.
- Animações suaves ao exibir as seções.
- Cards de habilidades e projetos.
- Links de contato.

## Estrutura

```text
portfolio-grid-bootstrap/
├── index.html
└── assets/
    ├── css/
    │   └── style.css
    ├── images/
    │   └── foto-perfil.jpg
    └── js/
        └── index.js
```

## Como executar

Abra o arquivo `index.html` no navegador. O projeto carrega Bootstrap e Font Awesome por CDN, então a conexão com a internet é necessária para esses recursos externos.

**Observação:** o formulário de contato está presente na interface, mas ainda não está conectado a um serviço para enviar mensagens.
