# 💼 Portfólio Grid com Bootstrap | Nicollas Rodrigo

Projeto de estudo em desenvolvimento front-end, criado para praticar interfaces responsivas e recursos interativos com HTML, CSS, JavaScript e Bootstrap.

## ✨ Destaques

- Layout responsivo com o sistema Grid do Bootstrap.
- Menu de navegação adaptável para telas menores.
- Alternância entre tema claro e escuro.
- Animações com respeito à preferência por movimento reduzido.
- Seções de apresentação, habilidades, projetos e contato.
- Formulário de contato integrado ao EmailJS e avisos com Toastify.

## 🛠️ Tecnologias

HTML5 · CSS3 · JavaScript · Bootstrap 5.3.3 · Font Awesome 6.7.2 · EmailJS · Toastify 1.12.0

## ▶️ Como executar

1. Clone ou baixe o repositório.
2. Abra a pasta do projeto no VS Code.
3. Inicie o `index.html` com o Live Server.
4. Mantenha a internet ativa para carregar as bibliotecas externas.

## ✉️ Formulário de contato

O envio pelo EmailJS foi testado e uma mensagem chegou ao Gmail. Para que o endereço de e-mail apareça corretamente no corpo da mensagem, confira no template do EmailJS a variável `{{email}}`, junto de `{{name}}`, `{{subject}}` e `{{message}}`.
