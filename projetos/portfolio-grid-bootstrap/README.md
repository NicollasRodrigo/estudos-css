# Portfólio Grid com Bootstrap

Portfólio responsivo desenvolvido para praticar HTML, CSS, JavaScript e Bootstrap 5.

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome

## Recursos

- Layout responsivo com o sistema de Grid do Bootstrap.
- Menu de navegação adaptado para telas menores.
- Alternância entre tema claro e escuro.
- Animações suaves ao exibir as seções.
- Cards de habilidades e projetos.
- Links de contato.

## Estrutura

```text
portfolio-grid-bootstrap/
├── index.html
└── assets/
    ├── css/
    │   └── style.css
    ├── images/
    │   └── foto-perfil.jpg
    └── js/
        └── index.js
```

## Como executar

1. Abra a pasta `portfolio-grid-bootstrap` no VS Code.
2. Inicie a página com uma extensão de servidor local, como Live Server. Não abra o HTML diretamente por duplo clique, pois o FormSubmit pode recusar formulários abertos como arquivos locais.
3. Mantenha a conexão com a internet para carregar Bootstrap e Font Awesome pelas CDNs.
