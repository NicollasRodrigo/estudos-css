# Meu Portfólio — CSS3

Projeto prático desenvolvido durante os estudos de **CSS3**, utilizando uma estrutura HTML5 como base para aplicar os estilos.

## Tecnologia principal

- CSS3

## Conteúdo

- Seletores CSS
- Box Model
- Cores e tipografia
- Espaçamento
- Menu de navegação
- Cards
- Formulários
- Pseudo-classe `:hover`
- Organização dos estilos em arquivo separado

## Estrutura

```text
portfolio-web/
├── css/
│   └── style.css
├── index.html
└── README.md
```

## Como usar

Abra o arquivo `index.html` no navegador ou utilize o Live Server no Visual Studio Code.

Os caminhos do áudio e do vídeo estão preparados no HTML para os arquivos locais correspondentes.
