# Meu Portfólio — HTML e CSS

Projeto prático desenvolvido durante os estudos de HTML5 e CSS3.

## Estrutura

- `index.html` — estrutura semântica da página e formulário.
- `css/style.css` — estilos, cores, espaçamentos, cards, menu e botão.
- `audio/` — arquivo de áudio usado na página, quando disponível.
- `video/` — arquivo de vídeo usado na página, quando disponível.

## Conteúdos praticados

- Seletores CSS
- Box Model
- Cores e tipografia
- Menu de navegação
- Seções e cards
- Formulários e validações HTML
- Botões e `:hover`
- Áudio e vídeo
- Organização do CSS em arquivo separado

## Observação

Os arquivos de áudio e vídeo originais não estavam presentes no ZIP enviado. Os caminhos já estão preparados no HTML para `audio/apresentacao.mp3` e `video/apresentacao.mp4`.
