# Atividade 06 — Aplicando CSS3 no Projeto de Portfólio

Esta atividade reúne os conteúdos trabalhados em aula sobre CSS3 aplicados a uma página de portfólio.

## Estrutura

- `index.html` — estrutura da página e formulário.
- `css/style.css` — estilos, cores, espaçamentos, cards, menu e botão.

## Conteúdos praticados

- Seletores por elemento, `id` e `class`
- Box Model
- Cores e tipografia
- Menu de navegação
- Cards de projetos
- Formulário e validações HTML
- Botões e `:hover`
- Organização do CSS em arquivo separado

## Observação

Os arquivos de áudio e vídeo usados localmente na aula não vieram no ZIP enviado para este repositório. O HTML mantém os caminhos preparados em `audio/apresentacao.mp3` e `video/apresentacao.mp4`; basta adicionar esses arquivos nessas pastas quando estiverem disponíveis.
